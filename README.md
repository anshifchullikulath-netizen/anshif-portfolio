## Run locally

### Option 1 — simplest
Open `index.html` in Chrome/Edge.

### Option 2 — recommended
Use VS Code + Live Server:
1. Install VS Code.
2. Open this folder.
3. Install the **Live Server** extension.
4. Right-click `index.html` → **Open with Live Server**.

The animation libraries and coding images are loaded from CDNs, so an internet connection is needed.

## Publish for everyone

### GitHub Pages
1. Create a GitHub account.
2. Create a new public repository, for example `anshif-portfolio`.
3. Upload `index.html`, `style.css`, and `script.js`.
4. Repository → Settings → Pages.
5. Select `Deploy from a branch`.
6. Choose `main` and `/root`.
7. Save.
8. GitHub will provide a public website address.

You can later connect a custom domain.
